# Preregistered compactification-selection test

This criterion is fixed before executing `exact_certificate.py` against the catalog.

## Physical input tuple and admissibility filter

For a ten-dimensional heterotic model `M=(X,G,V,W,H,rho)`, use only data that occur in the compactification construction: a smooth compact real-six-dimensional spin/CY internal space `X`; a free finite action `G` of degree `d=|G|`; an equivariant descended bundle `V`; integral characteristic/flux classes; the heterotic Bianchi/tadpole equation; and a modular-invariant, level-matched worldsheet completion. Four external dimensions are `10-6=4`, an input consequence of choosing a CY threefold, not an arithmetic output.

For a free quotient and descended chiral Dirac complex, require exact index descent `I_cover=d I_quotient`. In the standard embedding on a CY3, `I_cover=chi(X,TX)=Euler(X)/2` up to the declared representation/orientation convention. A target of three net families therefore passes exactly when `|Euler(X)|=6d`, after—not instead of—the geometry, freeness, descent, Bianchi, HYM and modular gates.

## Candidate arithmetic selector under test

The strongest admissible arithmetic statement is the preceding **consistency filter**. It is not yet a selector. The additional hypothesis tested is whether primality of `d`, or any partition/Ramanujan/Dedekind/nimber label not present in the action and index formula, is necessary or sufficient for `(D_external, |net|)=(4,3)`.

Predeclared falsifiers:

1. Same primality class with different net family count refutes sufficiency of that class.
2. A composite-order free quotient with net three refutes necessity of prime order.
3. Two physically admissible models with identical proposed arithmetic observables but different target outcomes prove non-identifiability on that observable set.
4. A rule using `p(n)`, Ramanujan residues, nim arithmetic, or Dedekind numbers without a sourced map from those objects into `(X,G,V,W,H,rho)` is rejected as an arbitrary relabeling, even if it fits this finite table.

No search over formulas, residues, sequence offsets, or mappings is permitted after catalog values are loaded. No alpha claim, `133` subtraction, or number fit is in scope.
