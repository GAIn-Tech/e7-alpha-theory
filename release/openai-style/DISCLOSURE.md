# Disclosure and non-claim ledger

## Authorship/process

This release package was prepared with AI assistance. The AI contribution is treated as drafting and orchestration, not as mathematical authority. Correctness must come from checked artifacts: exact arithmetic scripts, tests, and Lean where available.

## Relation to OpenAI-style proof releases

OpenAI's recent proof releases pair public explanation with machine-checkable Lean certificates and unusually explicit process disclosure. This package follows that release discipline: separate proof from narration, expose artifacts, state limitations, and invite independent review.

Primary public references used for the style mapping:

- OpenAI, "Ten advances in mathematics and theoretical computer science" — describes manuscripts, Lean certificates, model narration, and responsibility/disclosure language.
- OpenAI, "Solving (some) formal math olympiad problems" — describes neural theorem proving in Lean and tactic-based machine verification.
- OpenAI, "Our First Proof submissions" — discloses limited human supervision, expert feedback, selected attempts, and imperfect evaluation cleanliness.

## What this E7 package claims

- The E7 arithmetic identity `dim(E7) + fund(E7)/(2*rank(E7)) = 137` is exact when the standard table values `dim=133`, `fund=56`, `rank=7` are assumed.
- The repository contains many exploratory computations and hypotheses; this release package does not promote them into established physics.
- The literal equality `alpha^-1 = 137` is not a correct experimental statement at the Thomson/CODATA scale.

## What this E7 package does not claim

- It does not claim a solved physical derivation of the fine-structure constant.
- It does not claim a Clay/OpenAI-level new theorem.
- It does not claim that all historical experiment files are validated.
- It does not claim Lean proves empirical physics; Lean proves formal statements under definitions and assumptions.
- It does not claim that numerological proximity is physical evidence.

## Required reviewer posture

Treat the result as an audited release of a mathematical-physics hypothesis, not as a victory lap. The important outcome is the boundary: exact identity yes; physical derivation no; future work must add real predictive mechanism and independent empirical contact before upgrading the claim.
